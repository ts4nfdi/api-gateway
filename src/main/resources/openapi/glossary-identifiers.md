- **[URL](https://en.wikipedia.org/wiki/URL) (Uniform Resource Locator):** the address of a resource on the Web, e.g. `https://www.w3.org/RDF/`.
- **[URI](https://en.wikipedia.org/wiki/Uniform_Resource_Identifier) (Uniform Resource Identifier):** a unique sequence of characters that identifies an abstract or physical resource. Every URL is a URI, but a URI does not have to be resolvable.
- **[IRI](https://en.wikipedia.org/wiki/Internationalized_Resource_Identifier) (Internationalized Resource Identifier):** a URI that may also contain non-ASCII characters. Every URI is an IRI. In terminologies, classes, concepts, properties, and individuals are identified by IRIs, e.g. `http://purl.obolibrary.org/obo/NCIT_C2984`.

So: URL ⊂ URI ⊂ IRI. In practice, the gateway treats *IRI* and *URI* as the same thing. They are used as follows:

| Name | Where | Meaning                                                                                                                                                                                                                                              |
|------|-------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `{id}` | path of `/artefacts/{id}/...` | The short name or identifier of an artefact, i.e. its `short_form` in the `GET /artefacts` response (e.g. `ncit`, `agrovoc`). If several providers host an artefact with the same short name, all of them are queried; use `database` to choose one. |
| `{uri}` | path of `/artefacts/{id}/resources/.../{uri}` | The full IRI of a term, **URL-encoded**, e.g. `http%3A%2F%2Fpurl.obolibrary.org%2Fobo%2FNCIT_C2984`.                                                                                                                                                 |
| `uri` | query parameter of `.../children` and `.../tree` | The full IRI of a class or concept, e.g. `uri=http://purl.obolibrary.org/obo/NCIT_C2984`.                                                                                                                                                            |
| `{onto}`, `{class}`, `{property}`, `{individual}`, `{entity}` | paths of the OLS endpoints | Same as `{id}` and `{uri}` above, named as in OLS.                                                                                                                                                                                                   |
| `iri` | response field | The full IRI of an artefact or term.                                                                                                                                                                                                                 |
| `short_form` | response field | The short, local identifier of an artefact (e.g. `ncit`) or term (e.g. `NCIT_C2984`).                                                                                                                                                                |
| `id` | terminology collections | A UUID and W3CID generated by the gateway; used as `collectionId`.                                                                                                                                                                                   |
