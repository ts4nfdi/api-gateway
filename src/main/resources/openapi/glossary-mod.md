- **MOD (Metadata for Ontology Description and Publication):** a vocabulary for describing semantic artefacts. MOD extends [DCAT](https://www.w3.org/TR/vocab-dcat/), the W3C vocabulary for describing catalogues and datasets. The [MOD-API](https://github.com/FAIR-IMPACT/MOD-API) defines a common REST API for catalogues of semantic artefacts. The endpoints in the groups starting with **MOD** follow this API.
- **Catalogue:** a service that publishes metadata records about semantic artefacts and their available resources or distributions. The MOD-API offers operations for catalogue information, records, search, and service documentation. The gateway itself acts as one catalogue that combines the catalogues of all connected terminology services (see `GET /`).
- **Semantic artefact (short: artefact):** an umbrella term for ontologies, terminologies, taxonomies, thesauri, vocabularies, metadata schemas, and semantic standards. In this API, *artefact*, *terminology*, and *ontology* are used largely as synonyms.
- **Semantic resource:** a concrete, published or accessible representation of an artefact, e.g. an RDF download, an OWL file, a JSON-LD distribution, or an API endpoint. Note that in the gateway paths, `/artefacts/{id}/resources/...` is used for the *content* of an artefact (its classes, concepts, properties, ...).

**MOD endpoints vs. OLS endpoints:** the **MOD** groups are the native API of the gateway (paths `/search`, `/artefacts/...`) and use the MOD terminology. The **OLS4 v2** and **OLS4** groups (paths `/ols/api/...`, `/ols4/api/...`) offer the same data with the paths, parameters, and response format of the [Ontology Lookup Service (OLS)](https://www.ebi.ac.uk/ols4/), so that existing OLS clients can use the gateway without changes.
