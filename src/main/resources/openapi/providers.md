The following providers are connected by default (as of October 2026). The live list of the running gateway is returned by `GET /config/databases`. 
Use the values of the *Name* or *Type* column in the `database` parameter.

| Name | Type | Provider |
|------|------|--------|
| `agroportal` | `ontoportal` | [AgroPortal](https://agroportal.lirmm.fr) – agri-food |
| `earthportal` | `ontoportal` | [EarthPortal](https://earthportal.eu) – earth and environmental sciences |
| `biodivportal` | `ontoportal` | [BiodivPortal](https://biodivportal.gfbio.org) – biodiversity |
| `ecoportal` | `ontoportal` | [EcoPortal](https://ecoportal.lifewatch.eu) – ecology |
| `lovportal` | `ontoportal` | LOVPortal – Linked Open Vocabularies |
| `ebi` | `ols2` | [EMBL-EBI OLS4](https://www.ebi.ac.uk/ols4/) – life sciences |
| `tib` | `ols2` | [TIB Terminology Service](https://terminology.tib.eu) |
| `zbmed` | `ols2` | [ZB MED SemLookP](https://semanticlookup.zbmed.de) – life sciences |
| `berd` | `ols2` | [BERD@NFDI Terminology Service](https://ts.berd-nfdi.de) – business, economic and related data |
| `agrovoc` | `skosmos` | [AGROVOC](https://agrovoc.fao.org) (FAO) – agriculture |
| `zbmed-skosmos` | `skosmos` | [ZB MED Skosmos](https://semanticlookup.zbmed.de/skosmos/) |
| `gnd` | `gnd` | [GND](https://lobid.org/gnd) (Integrated Authority File, via lobid) |
| `dante` | `jskos` | [DANTE](https://dante.gbv.de) (GBV) |
| `coli-conc` | `jskos2` | [coli-conc](https://coli-conc.gbv.de) (GBV) |
| `iconclass` | `jskos2` | [Iconclass](https://iconclass.org) – art and iconography |
| `nerc` | `nerc` | [NERC Vocabulary Server](https://vocab.nerc.ac.uk) – marine and environmental sciences |
